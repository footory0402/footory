# Footory 영상 문구 가이드

## 목적
- 영상 업로드와 편집 전반의 문구를 쉬운 한국어로 통일한다.
- 사용자가 지금 해야 할 행동을 짧게 이해하게 만든다.
- 영어, 기술 용어, 불필요하게 긴 설명을 줄인다.

## 문구 기본 원칙
- 한 문장은 짧게 쓴다.
- 한 문구에는 한 행동만 담는다.
- 설명보다 행동을 먼저 보여준다.
- 내부 구현 용어를 그대로 쓰지 않는다.
- 어렵게 가르치는 말투보다 같이 안내하는 말투를 쓴다.

## 지금 쓰면 안 되는 문구 유형
- 영어 버튼, 영어 탭, 영어 상태 문구
- 내부 구현 용어를 그대로 드러내는 문구
- 한 문장에 기능 여러 개를 설명하는 긴 문구
- 사용자가 지금 하지 않아도 되는 행동을 먼저 권하는 문구
- 결과를 과하게 약속하거나 부담을 주는 문구
- 실패 이유를 길게 늘어놓는 문구

## 피해야 할 표현 예시
- `Trim`
- `Spotlight`
- `Overlay`
- `Highlight`
- `Reel Highlight`
- `single clip`
- `preview`
- `CTA`
- `메타데이터`
- `프로젝트`
- `편집 화면 준비 중입니다. 잠시만 기다려 주세요.`
- `다음 단계에서 세부 옵션을 조정할 수 있습니다.`

## 권장 표현 원칙
- `clip`은 내부 기준 단어로만 유지하고, 사용자에게는 `영상` 또는 `장면`을 먼저 쓴다.
- `highlight`는 사용자에게 `하이라이트`로 쓰되, 기본 기능처럼 보이게 하지 않는다.
- `reel highlight`는 `릴 하이라이트` 또는 `모아보기 하이라이트`처럼 결과 중심으로 쓴다.
- `overlay`는 `선수 정보`, `정보 넣기`, `정보 표시`로 바꾼다.
- `zoom`은 `확대`, `확대 재생`으로 바꾼다.

## 권장 한국어 문구 예시

| 상황 | 권장 문구 |
|---|---|
| 업로드 시작 제목 | 영상을 올려요 |
| 파일 선택 버튼 | 영상 고르기 |
| 길이 제한 | 5분 안의 영상만 올릴 수 있어요 |
| 용량 제한 | 200MB 안의 영상만 올릴 수 있어요 |
| 업로드 중 제목 | 영상을 올리고 있어요 |
| 업로드 완료 직후 | 이대로 저장하거나 편집할 수 있어요 |
| 구간 자르기 제목 | 보여줄 구간을 골라요 |
| 주인공 강조 제목 | 주인공을 골라요 |
| 주인공 선택 확인 | 이 선수를 볼게요 |
| 확대 원본 상태 | 원본으로 볼게요 |
| 확대 선택 | 조금 더 가까이 볼게요 |
| 프로필카드 표시 | 프로필카드를 보여줄게요 |
| 하단 선수정보 표시 | 아래에 선수 정보를 보여줄게요 |
| 저장 | 내 영상으로 저장 |
| 저장/편집 선택 | 이대로 저장할까요, 편집하고 저장할까요? |
| 건너뛰기 | 지금은 넘어갈게요 |
| 하이라이트 제안 | 짧게 다시 보여줄까요? |
| 릴 하이라이트 제안 | 여러 장면을 모아볼까요? |
| 오류 | 다시 해볼게요 |

## 버튼 톤 기준
- 버튼은 짧은 동사형으로 쓴다.
- 버튼 하나에 두 가지 행동을 넣지 않는다.
- 핵심 버튼은 확정형으로 쓴다.
- 보조 버튼은 유보형이나 완만한 종료형으로 쓴다.

## 버튼 예시
- 핵심 버튼: `이 구간으로 갈게요`
- 핵심 버튼: `이 선수를 볼게요`
- 핵심 버튼: `이대로 보여줄게요`
- 핵심 버튼: `내 영상으로 저장`
- 핵심 버튼: `편집하고 저장`
- 보조 버튼: `다시 보기`
- 보조 버튼: `지금은 넘어갈게요`
- 보조 버튼: `정보 없이 저장`
- 보조 버튼: `다른 영상 고르기`

## 라벨 톤 기준
- 라벨은 명사보다 바로 이해되는 짧은 말로 쓴다.
- `시작`, `끝`, `길이`, `이름`, `포지션`처럼 쉬운 낱말을 우선한다.
- 상태 라벨은 `진행 중`, `완료`, `다시 시도`처럼 바로 읽히게 쓴다.
- 장식적인 표현보다 뜻이 분명한 표현을 쓴다.

## 안내문 톤 기준
- 한 줄 안내를 기본으로 한다.
- 왜 막혔는지보다 지금 무엇을 하면 되는지부터 말한다.
- 딱딱한 공지 문장보다 짧은 안내 문장으로 쓴다.
- 같은 화면에서는 지금 가장 중요한 선택이 먼저 읽히게 쓴다.

## 안내문 예시
- 원하는 구간만 남겨보세요.
- 화면에서 선수를 한 번 눌러주세요.
- 원하면 그다음에만 조금 더 가까이 볼 수 있어요.
- 프로필카드와 아래 정보는 필요할 때만 켜도 돼요.
- 기본 정보만 보여줘도 충분해요.
- 저장한 뒤 하이라이트는 나중에 만들 수 있어요.
- 지금은 그대로 두고 넘어가도 괜찮아요.
- 필요한 것만 고르고 저장해도 돼요.

## 가장 먼저 바꿔야 할 문구 10개
1. `업로드 시작` → `영상 올리기`
2. `업로드 처리` → `영상을 올리고 있어요`
3. `메타데이터 확인` → `영상 정보를 확인하고 있어요`
4. `원본 업로드` → `영상 파일을 올리고 있어요`
5. `편집 화면 준비` → `곧 저장하거나 편집할 수 있어요`
6. `편집 화면으로 이동` → `편집하고 저장`
7. `single clip 편집 화면을 준비하는 중이에요.` → `한 장면 편집을 준비하고 있어요.`
8. `Trim` 또는 `trim` → `구간 자르기`
9. `Spotlight` 또는 `spotlight` → `주인공 강조`
10. `Overlay` 또는 `overlay` → `선수 정보 표시`

## 오버레이 문구 원칙
- 오버레이 관련 문구는 꾸미기보다 가림 방지를 먼저 알려준다.
- 첫 안내는 "영상이 가리지 않게 아래에 넣어보세요"처럼 safe area를 먼저 말한다.
- 정보가 많을수록 좋아 보인다는 인상을 주지 않는다.
- 이름, 포지션, 등번호 정도만 넣어도 충분하다는 메시지를 유지한다.

## 선택형 편집 문구 원칙
- 편집 도구 소개에는 `필수`, `꼭`, `반드시` 같은 표현을 쓰지 않는다.
- 건너뛰기 문구는 소극적 실패처럼 보이지 않게 쓴다.
- `그대로 둘게요`, `지금은 넘어갈게요`, `정보 없이 저장`처럼 부담 없는 표현을 쓴다.
- 선택하지 않아도 저장할 수 있다는 사실을 짧게 계속 확인시켜 준다.
- `이대로 저장`, `편집하고 저장`처럼 저장 전 선택 구조가 바로 읽히게 쓴다.
