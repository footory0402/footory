# Footory 영상 편집 화면 흐름

## 목적

- 영상 선택 후 저장하거나, 필요하면 편집하고 저장하는 화면 흐름을 단순화한다.
- 각 화면은 사용자가 우선순위를 빠르게 이해하도록 설계한다.
- 기본 흐름은 `clip` 저장까지이고, `highlight`와 `reel highlight`는 그 다음 단계로 분리한다.
- 주인공 선택, 구간 자르기, 프로필카드, 하단 선수정보는 모두 선택사항이다.

## 기본 흐름

1. 영상 선택
2. 업로드 중
3. 저장/편집 선택
4. 주인공 선택
5. 구간 자르기
6. 정보 표시 조정
7. 저장 완료

## 화면별 기준

| 화면 이름       | 사용자 목표                                      | 핵심 CTA         | 보조 CTA       | 고려 요소                                         | 다음 화면으로 넘어가는 조건                                |
| --------------- | ------------------------------------------------ | ---------------- | -------------- | ------------------------------------------------ | ----------------------------------------------------------- |
| 영상 선택       | 올릴 `clip`을 고른다                             | 영상 고르기      | 선수 프로필 편집 | 메인 업로드에서 두 진입을 함께 보여주는 구조 점검 | 영상 파일이 선택되고 길이와 용량 확인이 끝나면 업로드 중으로 이동 |

| 저장 완료       | 편집한 `clip`을 저장하고 바로 확인한다           | 내 영상으로 저장 | 바로 보기       | 저장 결과와 프로필 반영 위치 안내 점검             | 저장이 끝나면 종료 또는 프로필 이동                         |

## 화면별 세부 원칙

### 1. 영상 선택

- 제목은 짧게 쓴다.
- 파일 형식과 제한은 한 줄 또는 두 줄 안에서 끝낸다.
- 첫 화면의 중심은 `영상 고르기` 하나여야 한다.

### 2. 업로드 중

- 진행 상태는 3단계 이내로만 보여준다.
- "곧 저장할지 편집할지 고를 수 있다"는 점만 분명하면 된다.
- 완료 후에는 저장/편집 선택 화면으로 이어진다.

### 3. 저장/편집 선택

- 첫 선택은 `이대로 저장`과 `편집하고 저장`이면 충분하다.
- 사용자는 여기서 다시 영상을 바꿀 수 있어야 한다.
- 편집을 고르지 않아도 덜 완성된 느낌을 주지 않는다.

### 4. 주인공 선택

- 첫 행동은 영상에서 선수를 한 번 누르는 것으로 끝나야 한다.
- 사용자는 선택 직후 누가 주인공인지 바로 이해할 수 있어야 한다.
- 첫 온보딩이 있다면 영상 탭 영역처럼 실제 조작 지점만 짧게 안내한다.

### 5. 구간 자르기

- 사용자는 기본 구간을 그대로 두고 다음으로 넘어갈 수 있어야 한다.
- 이 화면의 중심은 시간 막대와 영상 재생이다.
- 시작과 끝을 고르는 일 외 설정은 최대한 숨긴다.
- 사용자는 지금 "어디를 남길지"만 판단하면 된다.

### 6. 정보 표시 조정

- 정보 없이 저장하는 경로를 기본 보조 CTA로 둔다.
- 기본은 최소 정보만 보여 주는 것이다.
- 이름, 포지션, 등번호 정도만 우선한다.
- 전체 프로필 편집은 여기서 하지 않는다.
- 미리보기에서 safe area를 함께 보여 줘야 한다.

### 7. 저장 완료

- 저장 이후 첫 선택은 `저장`과 `보기` 정도면 충분하다.
- 저장 이후 확장 기능을 억지로 열지 않는다.

## 상태 전이 원칙

- 업로드 완료 후 저장/편집 선택은 자동 또는 한 번의 탭으로 끝나야 한다.
- 저장 전까지는 상단 단계 이름을 고정해 길을 잃지 않게 한다.
- 뒤로가기는 이전 단계 하나만 돌아가게 한다.
- 온보딩은 모바일 화면 기준으로 검증하고, 하단 CTA를 가리는 상태로 배포하지 않는다.

## 가장 먼저 고쳐야 할 화면 3개

1. 업로드 중 화면: 업로드가 끝난 뒤 저장과 편집 중 무엇을 할 수 있는지 분명해야 한다.
2. 저장/편집 선택 화면: `이대로 저장`과 `편집하고 저장`의 차이가 즉시 읽혀야 한다.
3. 정보 표시 조정 화면: 영상이 얼마나 가려지는지보다 토글 조작이 먼저 보이지 않게 해야 한다.
