# Footory 영상 편집 화면 흐름

## 목적

- 영상 선택 후 저장하거나, 필요하면 편집하고 저장하는 화면 흐름을 단순화한다.
- 각 화면은 사용자가 우선순위를 빠르게 이해하도록 설계한다.
- 기본 흐름은 `clip` 저장까지이고, `highlight`와 `reel highlight`는 그 다음 단계로 분리한다.
- 장면 이동, 주인공 선택, 프로필카드, 하단 선수정보는 모두 선택사항이다.

## 기본 흐름

1. 영상 선택
2. 업로드 중
3. 저장/편집 선택
4. 한 화면에서 편집
5. 저장 완료

## 화면별 기준

| 화면 이름       | 사용자 목표                                      | 핵심 CTA         | 보조 CTA       | 고려 요소                                         | 다음 화면으로 넘어가는 조건                                |
| --------------- | ------------------------------------------------ | ---------------- | -------------- | ------------------------------------------------ | ----------------------------------------------------------- |
| 영상 선택       | 올릴 `clip`을 고른다                             | 영상 고르기      | 선수 프로필 편집 | 메인 업로드에서 두 진입을 함께 보여주는 구조 점검 | 영상 파일이 선택되고 길이와 용량 확인이 끝나면 업로드 중으로 이동 |
| 업로드 중       | 기다리는 동안 곧 저장할지 편집할지 고를 수 있음을 안다 | 영상 올리는 중   | 다른 영상 고르기 | 진행 상태 표현과 완료 후 선택 CTA 노출 방식 점검  | 업로드와 기본 정보 저장이 끝나면 저장/편집 선택으로 이동   |
| 저장/편집 선택        | 바로 저장할지, 조금 더 다듬을지 고른다                  | 이대로 저장      | 편집하고 저장   | 미리보기와 CTA 우선순위 점검                                  | 저장을 누르면 저장 완료, 편집을 누르면 한 화면 편집으로 이동 |
| 한 화면에서 편집 | 보여줄 구간, 주인공, 프로필카드, 하단 선수정보를 한 화면에서 끝낸다 | 저장 | 그대로 저장 | 하단 미니바, 영상 탭 재생, trim 핸들, 선수 선택, 정보 토글, safe area 점검 | 필요한 조정을 마치면 바로 저장 완료로 이동 |
| 저장 완료            | 편집한 `clip`을 저장하고 바로 확인한다                 | 내 영상으로 저장 | 바로 보기       | 저장 결과와 프로필 반영 위치 안내 점검                        | 저장이 끝나면 종료 또는 프로필 이동                            |

## 화면별 세부 원칙

### 1. 영상 선택

- 제목은 짧게 쓴다.
- 파일 형식과 제한은 한 줄 또는 두 줄 안에서 끝낸다.
- 첫 화면의 중심은 `영상 고르기` 하나여야 한다.

### 2. 업로드 중

- 진행 상태는 3단계 이내로만 보여준다.
- "곧 저장할지 편집할지 고를 수 있다"는 점만 분명하면 된다.
- 완료 후에는 저장/편집 선택 화면으로 이어진다.

### 3. 저장/편집 선택

- 첫 선택은 `이대로 저장`과 `편집하고 저장`이면 충분하다.
- 사용자는 여기서 다시 영상을 바꿀 수 있어야 한다.
- 편집을 고르지 않아도 덜 완성된 느낌을 주지 않는다.

### 4. 한 화면에서 편집

- 사용자는 먼저 하단 단일 타임라인으로 원하는 장면으로 이동할 수 있어야 한다.
- 같은 화면 안에서 시작과 끝을 바로 조정할 수 있어야 한다.
- 주인공 선택은 원하는 위치로 이동한 뒤 영상에서 선수를 한 번 누르는 것으로 끝나야 한다.
- 선수를 고른 직후 구도를 자동으로 확대하지 않고, 원하면 바로 아래에서만 확대를 고르게 한다.
- 프로필카드와 하단 선수정보 토글도 같은 화면의 하단 미니바에서 함께 조정해야 한다.
- 중앙 재생 오버레이, 단계 탭, 장문 설명 카드는 기본 편집 화면에 두지 않는다.
- 선택 직후에는 `프로필카드 -> 본영상 시작 -> 선택 시점 정지 -> 다시 재생` 흐름을 미리보기로 바로 이해할 수 있어야 한다.
- 첫 온보딩이 있다면 시간 막대와 영상 탭 영역처럼 실제 조작 지점만 짧게 안내하고, 큰 설명 카드는 두지 않는다.

### 5. 저장 완료

- 저장 이후 첫 선택은 `저장`과 `보기` 정도면 충분하다.
- 저장 이후 확장 기능을 억지로 열지 않는다.

## 상태 전이 원칙

- 업로드 완료 후 저장/편집 선택은 자동 또는 한 번의 탭으로 끝나야 한다.
- 저장 전까지는 상단 단계 이름을 고정해 길을 잃지 않게 한다.
- 뒤로가기는 이전 단계 하나만 돌아가게 한다.
- 온보딩은 모바일 화면 기준으로 검증하고, 하단 CTA를 가리는 상태로 배포하지 않는다.

## 가장 먼저 고쳐야 할 화면 3개

1. 업로드 중 화면: 업로드가 끝난 뒤 저장과 편집 중 무엇을 할 수 있는지 분명해야 한다.
2. 저장/편집 선택 화면: `이대로 저장`과 `편집하고 저장`의 차이가 즉시 읽혀야 한다.
3. 한 화면 편집: 설명보다 영상과 하단 미니바 조작이 먼저 보이게 해야 한다.
