# FOOTORY 기능 범위

> Last synced: 2026-04-10
> 이 문서는 MVP와 그 이후의 기능 우선순위를 고정한다. 범위 판단 기준은 [product-dna.md](./product-dna.md)와 [video-product-decisions.md](./video-product-decisions.md)다.

## 1. 범위 판단 기준

- Footory는 선수 커리어/어필 중심이다.
- Evidence > Opinion.
- Video-first, Clip-first.
- Team is context, not identity.
- 새 기능은 프로필, clip 포트폴리오, 태그 포트폴리오, 객관 지표, 팀 컨텍스트에 기여해야 한다.
- 영상 기능은 "예쁜 편집 앱"보다 "짧은 영상 빠른 업로드와 즉시 재생"이 우선이다.
- 하이라이트는 core가 아니라 optional editing이다.

## 2. Must Have

### 2.1 선수 프로필과 어필 구조

- 선수 프로필의 핵심 정보 구조 정리
- 포지션, 강점, 주발, 연령대, 활동 지역, 커리어 이력 등 기본 프로필 완성
- 공유했을 때 바로 선수 가치를 이해할 수 있는 프로필 랜딩 경험
- player profile card와 영상 하단 선수 정보 영역 유지

### 2.2 clip-first 영상 업로드와 재생

- 짧은 원본 영상 업로드
- 업로드 직후 메타데이터 추출과 썸네일 준비
- 업로드 후 바로 clip 재생 가능
- `clips` 메타데이터 기반 클라이언트 재생 유지
- spotlight 적용 재생
- zoom playback
- 프로필과 공유 경로에서 같은 clip 재생 계약 유지

### 2.3 최소 영상 편집의 core 저장 계약

- `trim_start`, `trim_end`, `highlight_start`, `highlight_end`, `duration_sec` 중심 저장 계약 유지
- `spotlight_x`, `spotlight_y`, `freeze_at`, `effects.trackingMode`, `effects.trackingPoints` 소비 경로 유지
- 프로필 featured 연결과 clip 태그 연결 유지

### 2.4 태그 포트폴리오

- 플레이 유형별 태그 체계
- 특정 태그 역량을 증명하는 clip 포트폴리오 구조
- 프로필과 clip 재생 경험에서 태그를 일관되게 연결하는 UX

### 2.5 객관 지표와 커리어 기록

- 시즌/기간 기준으로 관리되는 기록
- 측정 가능한 객관 지표 입력과 표시
- 날짜와 맥락이 남는 기록 히스토리
- 영상과 기록이 서로 연결되는 구조

### 2.6 팀 컨텍스트와 최소 보조 기능

- 현재/이전 소속 팀 정보
- 팀 활동 시기와 선수 커리어 연결
- 공유
- 검색
- 기본 탐색
- 보호자/코치/스카우트가 선수 자료를 보기 쉬운 접근성 개선

## 3. Optional Editing

### 3.1 선택형 편집 도구

- trim 조정
- spotlight 지정 또는 조정
- zoom playback 관련 설정
- player info overlay 조정
- lower third 노출 제어
- highlight range 설정

### 3.2 선택형 하이라이트 구성

- clip 내 대표 범위 지정
- 하이라이트 시작/종료 구간 조정
- 필요 시 대표 장면 지정
- 프로필 featured 후보 또는 태그 포트폴리오 연결 미세 조정

### 3.3 품질 보조 기능

- 썸네일 대표 프레임 조정
- 자동 제안값을 바탕으로 한 빠른 수정 UX
- 부모 또는 선수가 모바일에서 최소 입력으로 끝낼 수 있는 편집 흐름

## 4. Phase 2

### 4.1 서버 렌더와 export

- `render-worker/` 재정비
- `/api/render/*` 메인 복귀 여부 판단
- 서버 렌더 기반 결과물 export
- 별도 결과물 엔티티 분리 저장

### 4.2 고급 영상 제작 기능

- clip 여러 개를 조합하는 고급 하이라이트 제작
- 자동 하이라이트 추천 고도화
- 템플릿 기반 결과물 개선
- 기록과 영상의 자동 연결 추천

### 4.3 보조적 탐색과 협업 확장

- 스카우트/코치 관점의 고급 필터
- 코치 피드백 보관
- 보호자 보조 업로드 흐름 고도화
- 스카우트용 저장, 비교, 내부 메모 같은 B2B성 보조 기능

### 4.4 팀 기능 확장

- 팀 아카이브 정리
- 시즌 단위 팀 활동 문맥화
- 팀 단위 운영 기능

이 항목들은 선수 포트폴리오를 보강할 때만 추진한다. 팀 자체의 커뮤니티 활성화가 목표가 되어서는 안 된다.

## 5. 만들지 않을 것

### 5.1 소셜 피드 중심 기능

- MVP에서 과도한 소셜 피드화 금지
- 반응 유도형 메인 피드 확장
- 체류 시간 중심 추천 알고리즘
- 밈성 콘텐츠 소비를 위한 릴스형 무한 피드
- 댓글/반응/팔로우를 제품 중심축으로 재설계하는 시도

### 5.2 주관 평가와 서열화 기능

- 주관적 평점/별점/랭킹 기능 금지
- 인기투표형 선수 순위
- 별점 평가
- 감상 위주의 리뷰 점수
- 근거 없는 종합 랭킹

### 5.3 편집 앱화되는 기능

- 모든 clip에 하이라이트 생성을 강제하는 구조
- 과도한 스티커, 필터, 장식 위주의 편집
- 결과물보다 편집 재미를 우선하는 기능
- 범용 숏폼 제작 앱처럼 가는 기능 확장
- 선수 어필과 무관한 연출 중심 편집 도구

## 6. 기능 추가 승인 규칙

새 기능은 아래 중 하나 이상을 분명히 개선해야 한다.

- 짧은 clip 업로드 속도와 이해도
- 업로드 직후 재생 가능성
- spotlight와 zoom playback 품질
- 프로필 전달력
- 태그 포트폴리오 누적 가치
- 객관 지표의 신뢰도와 가독성
- 팀 컨텍스트의 설명력

위 항목에 직접 기여하지 못하면 기본값은 "지금 만들지 않는다"다.
